# 株価可視化・分析アプリ

Pythonで開発した、複数銘柄の株価を可視化・比較・予測するWebアプリです。

**公開URL:** https://gms.gdl.jp/~fuchiko/stock/
---

## 背景

データサイエンス学部のゼミ研究の一環として、株価データを題材に「データ取得 → 可視化 → 分析 → 予測」までの一連のフローを自分の手で実装することを目的に開発しました。Streamlitを用いることで、Pythonコードのみでインタラクティブな分析ダッシュボードを構築できる点に興味を持ち、技術検証を兼ねて選定しました。

---

## 機能

- **複数銘柄の同時比較**：最大2銘柄を指定し、開始時点を100として正規化したグラフで推移を比較
- **サマリーカード表示**：現在価格、変動率、最高値・最安値、ボラティリティ、最大ドローダウン、シャープレシオを一覧表示
- **急騰・急落アラート**：日次リターンが±3%を超えた日を自動検出して表示
- **株価予測モデル**：線形回帰により30営業日先までの株価を予測、MAEとR²で精度を可視化
- **移動平均線**：単一銘柄選択時に25日・75日移動平均を重ねて表示
- **期間選択**：1ヶ月〜5年の範囲で分析期間を可変

---

## 技術スタック

- **言語**：Python 3
- **フレームワーク**：Streamlit
- **データ取得**：yfinance（Yahoo Finance API）
- **可視化**：Plotly
- **データ処理**：pandas, NumPy
- **機械学習**：scikit-learn（LinearRegression）
- **ホスティング**：Streamlit Community Cloud

---

## 使い方

1. 公開URLにアクセス
2. 期間を選択（例：1y）
3. 銘柄1・銘柄2に銘柄コードを入力
   - 米国株：`AAPL`（Apple）、`NVDA`（NVIDIA）など
   - 日本株：`7203.T`（トヨタ）、`6758.T`（ソニー）など
4. グラフ・予測・指標が自動で表示されます
